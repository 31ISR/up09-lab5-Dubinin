📝 Django Blog Project

## 📋 Описание проекта
Это современный блог-проект, разработанный с использованием Django 5.1.4 Проект предоставляет платформу для создания и управления блог-постами, группами с поддержкой изображений и текстового контента.

## 🛠 Технологии
- Python
- Django 5.1.4
- Pillow
- SQLite

## ⚙️ Требования

- Python 3.8+
- pip (менеджер пакетов Python)
- Виртуальное окружение (рекомендуется)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone shh
```
Откроеться папка туда надо закинуть shh ключи

### 2. Создание вертуального окружения

```bash
python -m venv venv
```

### 3. Активация виртуального окружения

Для Windows:
```bash
venv\Scripts\activate
```

Для Linux/MacOS:
```bash
source venv/bin/activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Настройка базы данных
```bash
python manage.py migrate
```

### 6. Создание суперпользователя
```bash
python manage.py createsuperuser
```

### 7. Запуск сервера разработки
```bash
python manage.py runserver
```

## 🌟 Основные функции

- Создание, редактирование и удаление блог-постов
- Создание своих групп, и их удаление
- Загрузка изображений

## ‍💻 Использование

### Административная панель

1. Перейдите по адресу `http://127.0.0.1:8000/admin/`

2. Войдите, используя учетные данные суперпользователя

3. Управляйте постами, пользователями и другим контентом
